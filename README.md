# Portafolio de Flavio Morales

Mi portafolio web personal: quién soy, qué tecnologías uso, mis proyectos y cómo contactarme.

🌐 **Ver en línea:** [flavio6931.github.io/portafolio](https://flavio6931.github.io/portafolio/)

## ✨ Características

- **Diseño en blanco y negro** con efectos de cristal (glassmorphism), brillo al pasar el cursor y animaciones suaves.
- **Bilingüe (español / inglés)**: botón para cambiar de idioma; la preferencia se recuerda en el navegador.
- **Filtros de proyectos** por categoría: Android, PC, IA, Web y Extensiones.
- **Demos en video** dentro de una ventana emergente, que se cargan solo al abrirlas.
- **Formulario de contacto** que envía correos reales con [Web3Forms](https://web3forms.com/), sin salir de la página.
- **Descarga del CV** en PDF.
- **Adaptado a móviles**: menú lateral y efectos táctiles para Android e iOS.
- **Optimizado**: imágenes en WebP, carga diferida de imágenes y videos comprimidos con inicio rápido.

## 🛠️ Tecnologías

HTML5 semántico, CSS3 y JavaScript sin frameworks. Iconos de [Font Awesome](https://fontawesome.com/) y fuentes de [Google Fonts](https://fonts.google.com/) (Outfit y Space Grotesk). Publicado con GitHub Pages.

## 📁 Estructura

```
index.html            página principal
css/diseno.css        estilos
js/Logica.js          interactividad, traducciones y formulario
assets/images/        fotos, capturas e iconos de tecnologías
assets/videos/        demos de los proyectos
assets/docs/          CV en PDF
```

## 💻 Verlo en tu equipo

No necesita instalación. Desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Y abre <http://localhost:8000> en el navegador.
